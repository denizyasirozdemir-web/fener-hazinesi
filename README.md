# Fenerin Hazinesi · The Lantern Vault

Elinde fenerle karanlık yeraltı harabelerinde hazine arayan bir kaşifin 2D macera platform oyunu.
A 2D adventure platformer: a lantern-carrying explorer searches dark underground ruins for treasure.

**▶ Oyna / Play:** https://denizyasirozdemir-web.github.io/fener-hazinesi/

Bronz ve gümüş anahtarları bul, kilitli odaları aç, Bekçiyi yen ve gizli hazineye ulaş.
Find the bronze and silver keys, open the locked chambers, defeat the Guardian and reach the hidden vault.

| Tuş / Key | |
|---|---|
| ← → / A D | koş / run |
| Boşluk / Space / W | zıpla / jump |
| E | kol, sandık / lever, chest |
| ↓ + Boşluk | raftan in / drop down |
| M | harita / map |
| Esc | duraklat / pause |

Dokunmatik ekran ve oyun kolu desteklenir. Touch and gamepad supported.
Bağımlılık yok: saf HTML5 Canvas, sesler koddan sentezlenir. No dependencies.

`tools/bot.py`: oyunu baştan sona gerçek fizikle çözen doğrulama botu (Python + Playwright).
